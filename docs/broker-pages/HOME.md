# Broker Home Dashboard

**Route:** `/broker/home`

## Overview

Your Broker Home dashboard is the central hub of your broker portal, providing a comprehensive overview of your client portfolio, recent application activity, and business performance metrics at a glance.

## What You'll See

### Client Portfolio Summary

- Total number of clients in your portfolio
- Active clients vs. inactive clients
- New clients added this month
- Client distribution by status

### Application Activity

- Total applications submitted
- Applications pending review
- Applications approved
- Applications rejected
- Recent application updates

### Commission Overview

- Total commissions earned
- Pending commissions
- Paid commissions this month
- Year-to-date earnings
- Commission breakdown by product

### Recent Client Activity

- Latest client registrations
- Recent funding applications
- Status changes and updates
- Client action items requiring attention

### Performance Metrics

- Approval rate percentage
- Average application processing time
- Client satisfaction ratings
- Monthly performance trends

### Product Performance

- Most popular funding products
- Success rates by product type
- Product recommendations based on trends

## Visual Features

- **Charts:** Visual breakdown of your portfolio and application statuses
- **Progress Bars:** Monthly goals and performance indicators
- **Status Badges:** Color-coded status indicators for quick reference
- **Alert Cards:** Important notifications and action items
- **Activity Feed:** Real-time updates on client and application activity

## Quick Actions

From your dashboard, you can:

- **Add New Client** - Quickly onboard a new client to your portfolio
- **Submit Application** - Start a new funding application for a client
- **View Products** - Browse available funding products
- **Schedule Call** - Book consultation with support team
- **Generate Report** - Export client or commission reports

## Dashboard Widgets
