# My Clients

**Route:** `/broker/my-clients`

## Overview

Your My Clients page provides comprehensive management tools for all clients in your portfolio. View detailed client information, track funding applications, monitor account activity, and manage relationships from a centralized dashboard.

## What You'll See

### Client Portfolio Overview

- Total number of clients in your portfolio
- Active clients vs. inactive clients
- New clients this month
- Client growth trends
- Client distribution by status
- Portfolio performance metrics

### Client List

- Complete roster of all assigned clients
- Client contact information
- Account status indicators
- Onboarding completion status
- Last activity date
- Associated funding applications
- Application status summary

### Client Details

For each client, view:

- Full name and contact information
- Email address and phone number
- Business information (if applicable)
- Account creation date
- Onboarding status
- Funding application history
- Current application status
- Document submission status
- Credit report status
- Bank account connections
- Last login activity

### Search and Filter

- Search by client name, email, or business name
- Filter by account status (active, pending, inactive)
- Filter by onboarding status
- Filter by application status
- Sort by name, date added, or last activity
- View recently added clients
- View clients requiring attention

## Visual Features

- **Status Badges:** Color-coded indicators for quick status identification
- **Activity Timeline:** Visual representation of client journey
- **Application Progress:** Progress bars showing application completion
- **Document Status:** Icons indicating document submission status
- **Quick Stats Cards:** Key metrics for each client at a glance
- **Action Buttons:** Quick access to common client management tasks

## Client Status Indicators

### Account Status

- **Active** - Client is actively using the platform
- **Pending** - Client registration pending completion
- **Inactive** - No recent client activity
- **Onboarding** - Client completing initial setup
- **Verified** - Client identity and information verified

### Application Status

- **No Applications** - Client hasn't started any applications
- **In Progress** - Application partially completed
- **Submitted** - Application under admin review
- **Approved** - Funding approved
- **Rejected** - Application not approved
- **Funded** - Funding disbursed

### Document Status

- **Complete** - All required documents submitted
- **Incomplete** - Documents missing or pending
- **Under Review** - Documents being verified
- **Rejected** - Documents require resubmission
