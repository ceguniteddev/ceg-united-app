# Admin Home Dashboard

**Route:** `/admin/home`

## Overview

Your Admin Home dashboard provides a comprehensive command center for monitoring and managing the entire platform. View real-time statistics, track key metrics, and access critical administrative functions from one centralized location.

## What You'll See

### Platform Statistics

- Total registered users (clients and brokers)
- Active users vs. inactive users
- New registrations today/this week/this month
- User growth trends
- User distribution by role

### Application Overview

- Total funding applications submitted
- Applications pending review
- Applications approved this month
- Applications rejected
- Average processing time
- Application conversion rate

### Financial Metrics

- Total funding approved (month/year)
- Total Denefits payments processed
- Pending payment transactions
- Revenue metrics
- Payment success rate
- Outstanding balances

### Support Statistics

- Open call requests
- Average response time
- Resolved requests today
- Pending support tickets
- Client satisfaction ratings
- Support team performance

### System Health

- Platform uptime status
- Active user sessions
- System performance metrics
- Recent error logs
- API status
- Database health indicators

### Recent Activity

- Latest user registrations
- Recent application submissions
- New support requests
- Payment transactions
- Document uploads
- System alerts

## Visual Features

- **Real-time Charts:** Live data visualization of key metrics
- **Progress Indicators:** Visual representation of goals and targets
- **Status Badges:** Color-coded status for quick identification
- **Alert Cards:** Critical notifications requiring immediate attention
- **Activity Feed:** Chronological stream of recent platform events
- **Heat Maps:** User activity patterns and peak usage times

## Quick Actions

From your dashboard, you can:

- **Review Applications** - Jump to pending funding applications
- **Manage Users** - Quick access to user management
- **Process Payments** - View and manage payment transactions
- **Respond to Requests** - Access open call requests
- **Create Announcement** - Post new platform updates
- **Generate Report** - Export analytics and reports
- **Manage Products** - Update funding or bank products
- **Enroll Users** - Add users to educational courses

## Alert Notifications

Monitor critical alerts:

- **Red Indicators** - Urgent items requiring immediate action
  - New funding applications awaiting review
  - Open call requests pending response
- **Warning Alerts** - Items approaching deadline or limits
- **System Alerts** - Technical issues or maintenance notifications
- **Compliance Alerts** - Regulatory or policy matters
