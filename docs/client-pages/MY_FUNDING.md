# My Funding

**Route:** `/client/my-funding`

## Overview

Manage all your funding applications in one centralized location. Apply for new funding, track application status, and stay updated throughout the approval process.

## Features

### Apply for New Funding

Easily start a new funding application with:
- Business selection from your registered businesses
- Funding amount specification  
- Funding type selection (working capital, equipment financing, etc.)
- Description of funding purpose
- Document upload capability

### View All Applications

Track your funding applications with complete visibility:

**Application Information:**
- Unique application ID for reference
- Associated business name
- Requested funding amount
- Current status with color-coded badges
- Application submission date
- Last update timestamp

**Application Statuses:**
- **Pending** - Submitted and awaiting review
- **Under Review** - Being evaluated by our team
- **Additional Information Required** - Action needed from you
- **Approved** - Funding approved! Next steps provided
- **Rejected** - Application declined with reason

### Application Management

For each application, you can:
- View complete application details
- Upload additional supporting documents
- Edit draft applications before submission
- Delete draft applications
- Download funding agreements (approved applications)

### Search and Filter

Find applications quickly:
- Filter by status (pending, approved, rejected, etc.)
- Search by business name or application ID
- Filter by date range
- Sort by date, amount, or status

### Application Timeline

Track your application's journey:
- Submission date
- Status change history
- Document submission dates
- Review milestones
- Final decision date

## How to Apply

1. Click "Apply Funding" button
2. Select your business
3. Enter funding details (amount, type, purpose)
4. Upload required documents
5. Review and submit
6. Track status in your applications list

## Status Updates

Stay informed with:
- Email notifications for status changes
- Document request alerts
- Approval/rejection notifications
- Reminders for incomplete applications

## Required Documents

Typical documents needed:
- Business license
- Bank statements
- Income verification
- Business tax returns
- Financial statements

## Best Practices

- Provide accurate and complete information
- Upload all required documents upfront
- Respond quickly to document requests
- Keep your business information current
- Review application before submitting

- **Home** - Return to dashboard
- **My Business** - Manage business entities
- **My Documents** - Upload required documents
