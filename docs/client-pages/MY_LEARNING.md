# My Learning

**Route:** `/client/my-learning`

## Overview

Access educational courses, track your learning progress, complete lessons, watch video content, and earn certificates. Available exclusively to premium members.

> **Note:** This feature requires premium client status (active Denefits contract).

## Access Requirements

To access My Learning, you need:
- Active premium membership
- Valid Denefits contract
- Payment in good standing

**Non-Premium Users:** If you don't have premium access, you'll see a message to upgrade or contact support.

## Features

### Course Dashboard

Your learning hub displays:
- **Total Enrolled Courses** - All your courses
- **In Progress** - Courses you've started
- **Completed** - Finished courses with certificates
- **Learning Hours** - Total time spent learning
- **Certificates Earned** - Your achievements

### Course List

Browse all your enrolled courses:

**Course Information:**
- Course thumbnail image
- Course title and description
- Instructor name
- Progress bar showing completion percentage
- Course status badge
- Total duration
- Number of lessons
- Last accessed date

**Course Status:**
- 🔵 Not Started - Haven't begun yet
- 🟡 In Progress - Currently learning
- 🟢 Completed - Finished all lessons
- 🏆 Certified - Completed with certificate

**Course Actions:**
- **Continue Learning** - Resume where you left off
- **View Details** - See full course information
- **Download Certificate** - For completed courses

### Course Details

Each course includes:

**Overview:**
- Full course description
- Learning objectives
- Prerequisites
- Skill level (Beginner, Intermediate, Advanced)
- Course language
- Last updated date

**Curriculum:**
- Organized into modules
- Individual lessons listed
- Duration estimates
- Completion checkmarks
- Locked lessons (if sequential)

### Lesson Viewer

Watch and learn:

**Video Lessons:**
- High-definition streaming
- Adaptive quality based on connection
- Playback controls (play, pause, seek)
- Volume and speed controls
- Fullscreen mode
- Picture-in-picture
- Captions/subtitles (if available)
- Resume from where you left off

**Lesson Features:**
- Lesson title and description
- Video transcript
- Downloadable resources
- Note-taking area
- Bookmark timestamps

**Lesson Navigation:**
- Previous lesson button
- Next lesson button
- Return to course overview
- Jump to any lesson
- Auto-advance option

### Progress Tracking

Your progress is automatically saved:

**Completion Criteria:**
- Video lessons: Watch at least 80% of video
- Reading lessons: Complete full content
- Quizzes: Pass with required score

**Progress Display:**
- Overall course percentage
- Module-by-module progress
- Time spent in course
- Last activity timestamp
- Next lesson highlighted

### Assessments and Quizzes

Test your knowledge:

**Quiz Types:**
- Knowledge checks after sections
- Module tests
- Final exams
- Practice quizzes

**Quiz Features:**
- Multiple choice questions
- True/false questions
- Instant feedback
- Correct answer explanations
- Multiple attempts allowed
- Score tracking

**Passing:**
- Typical passing score: 70-80%
- Retry if you don't pass
- Best score recorded

### Certificates

Earn certificates upon completion:

**Certificate Includes:**
- Your name
- Course title
- Completion date
- Unique certificate ID
- Instructor signature
- Company seal

**Certificate Actions:**
- **Download PDF** - High-quality certificate
- **Share** - Post to LinkedIn or social media
- **Verify** - QR code for verification
- **Print** - Printer-friendly format

### Course Resources

Access supplementary materials:
- Course PDFs and slide decks
- Workbooks and exercises
- Code files and samples
- Templates and forms
- Reference materials
- Checklists

**Download Options:**
- Individual file download
- Organized by module
- Available after course completion

### Learning Analytics

Track your learning:
- Total learning time
- Courses enrolled vs. completed
- Completion rate percentage
- Average quiz scores
- Learning streak (consecutive days)
- Achievement badges

**Achievement Badges:**
- First course completed
- 5 courses completed
- Perfect quiz score
- Learning streaks (7, 30, 90 days)
- Speed learner recognition

## How to Learn

1. Browse enrolled courses
2. Click "Continue Learning" or "Start Course"
3. Watch video lessons
4. Take notes during lessons
5. Download resources
6. Complete quizzes
7. Finish all modules
8. Pass final assessment
9. Receive certificate
10. Share your achievement

## Course Completion

When you complete a course:
1. System marks course as 100% complete
2. Certificate automatically generated
3. Celebration message displayed
4. Certificate available for download
5. Badge updated to "Certified"

## Best Practices

- Learn at your own pace
- Take notes during lessons
- Complete exercises and assignments
- Review difficult concepts
- Apply what you learn
- Complete courses in order
- Track your progress
- Earn all certificates

## Troubleshooting

Common issues:
- **Can't Access** - Check premium status
- **Video Won't Play** - Check internet connection
- **Progress Not Saving** - Wait for auto-save, don't close browser
- **Certificate Not Available** - Ensure all lessons and quizzes are complete

## Navigation

- **Home** - Return to dashboard
- **Course Detail** - Click course card
- **Lesson Viewer** - Click Continue Learning
